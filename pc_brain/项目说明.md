## 一、这个项目是什么

复刻《流浪地球》里的超级 AI「550W（MOSS）」。目标形态是：一个带 OLED 眼睛、步进电机（会转头）、LED 灯环、蜂鸣器的 ESP32 实体，接上 PC 端「大脑」后，能**看**（摄像头）、**听**（麦克风）、**说**（语音合成）、**想**（大模型）、**动**（电机/灯/蜂鸣器）。

项目按「阶段」推进，共 19 个阶段，目前**代码层面全部完成**。

## 四、它怎么工作（架构）

```
摄像头 ──→ 视觉线程（目标检测 + 在场跟踪 + 运动检测）
麦克风 ──→ 听觉线程（AEC 回声消除 + 音量/拍手/切句）
                        │
                        ▼
              识别线程 AsrWorker（whisper：声音→文字）
                        │
                        ▼
        ┌── 主循环 20Hz 融合（防抖动）──┐
        │                               │
   状态变化                         听懂一句话
        │                               │
        ▼                               ▼
  MODE 发给设备              语言线程 MindWorker（大模型/离线模板）
                                    │
                                    ▼
                          语音线程 SpeakWorker（TTS 念出来）
                                    │
                                    ▼
                          一条串口 MODE/TEXT → ESP32
```

**核心思想**：眼睛和耳朵各跑各的线程，最终在主循环里「融合」成一个状态；只有状态变化或听懂了你说话，才触发「说话」和「发指令给设备」。

## 五、怎么跑（操作速查）

### 前置
- Python 必须用项目 venv：`pc_brain\.venv\Scripts\python.exe`（不要用系统 Python）
- 命令都在 `pc_brain` 目录下执行

### 1. 一键启动（推荐，需先填 Key）
编辑 `pc_brain\启动MOSS.bat`，把 `your-deepseek-key` 换成真实 DeepSeek Key，然后双击。

### 2. 命令行启动（真实摄像头 + 麦克风 + 自由对话）
```powershell
cd C:\Users\hp\Documents\PlatformIO\Projects\550W_Sim\pc_brain
.\.venv\Scripts\python.exe moss_brain.py --llm api --api-base "https://api.deepseek.com/v1" --model deepseek-chat --api-key "你的key" --no-echo-guard
```

### 3. 无硬件演示（全合成）
```powershell
.\.venv\Scripts\python.exe moss_brain.py --demo --audio-source tools/assets/ask_time.wav --asr whisper --llm offline
```

### 已固化的默认值（不用每次敲）
`--tts sapi`、`--asr whisper`、`--narrate quiet`、`--narrate-gap 9999`（开机只说一次）、`--wake-ack voice`（喊名字应「在」）、`--aec off`、`--vision-source 0`、`--audio-source mic`、唤醒词 `BOSS`。

## 六、关键参数速查

| 参数 | 作用 | 常用值 |
|---|---|---|
| `--llm` | 语言后端 | `off`/`offline`/`api`/`auto` |
| `--api-base` / `--model` / `--api-key` | 大模型接入 | DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat` |
| `--asr` | 语音识别 | `whisper`（本地）/`off` |
| `--tts` | 语音合成 | `sapi`（离线）/`edge`（在线）/`off` |
| `--vision-source` | 画面来源 | `0`（摄像头）/`demo`/图片路径 |
| `--audio-source` | 声音来源 | `mic`/`demo`/`xxx.wav` |
| `--wake-word` | 唤醒词 | 默认 `boss`（含中文同音别名） |
| `--wake-ack` | 叫醒应声 | `voice`（说「在」） |
| `--narrate` / `--narrate-gap` | 话痨控制 | `quiet` / `9999`（开机只说一次） |
| `--aec` | 回声消除 | `off`（耳机）/`on`/`auto` |
| `--port` | 接设备 | `socket://127.0.0.1:4011`（假设备） |
| `--demo` | 全合成总开关 | 强制切摄像头/麦克风为合成 |

## 八、本项目特有的工程约定（踩坑沉淀）

1. **换真机只改 `config.h`**（阶段 5 拆 HAL 的回报，PC 端 19 阶段代码回真机一行不用改）。
2. **注释用中文，记录「为什么」和走过的弯路**，不只写「是什么」。
3. **判据两个方向都测**：既测「该响的时候响」，也测「不该响的时候别响」。
4. **同一件事绝不写两份实现**（判断/排序/判据）——两份迟早漂，漂了不报错。
5. **夹具不能造假数据**——夹具造假，结论就是假的。
6. **测试要么稳定过、要么稳定不过**，「偶尔红」最消耗人。
7. **断言写错和代码写错看起来一样**——写断言前先手算期望值。
8. **接缝才是 bug 藏身处**——每段自检都绿，合起来可能出问题，要有串起来的探针。

## 十一、遇到问题怎么排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError` | 用了系统 Python | 用 `pc_brain\.venv\Scripts\python.exe` |
| `can't open file moss_brain.py` | 目录不对 | 先 `cd ...\pc_brain` |
| 只回「我收到了你说的是…」 | 大模型没接上 | 检查 `--llm api --api-key` |
| 画面是小篮球晃 | 开了 `--demo` | 去掉 `--demo`，用 `--vision-source 0` |
| 听不到你说话 | `--demo` 覆盖了麦克风 | 去掉 `--demo`，用 `--audio-source mic` |
| `--wav` 报错 | 没这参数 | 用 `--audio-source xxx.wav` |
| 喊名字没反应 | whisper 转写不同 | 换用默认 `boss`（已配同音别名） |
